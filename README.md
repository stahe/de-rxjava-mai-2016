---

## 📘 Überblick

Dieses Dokument richtet sich an erfahrene Java-Entwickler, die **reaktive Programmierung** mit **RxJava** und seinen Varianten erlernen und in die Praxis umsetzen möchten.

Im Gegensatz zu einem traditionellen theoretischen Ansatz basieren die Inhalte hauptsächlich auf **konkreten Beispielen**, die jeweils mit Erläuterungen versehen sind und einen schlüssigen Lernpfad bilden.

---

## ⚙️ Kontext und Ziele

Reaktive Programmierung zielt darauf ab, Folgendes zu vereinfachen:

* den Umgang mit Asynchronität
* die Verarbeitung von Datenströmen
* das Ereignismanagement

Dieses Dokument basiert auf dem **ReactiveX**-Ökosystem, das eine beobachtbare, datenstromorientierte API für die asynchrone Programmierung bereitstellt.

---

## 🔁 ReactiveX und RxJava

ReactiveX ist eine Sammlung von Bibliotheken zur Bearbeitung von **beobachtbaren Datenströmen**.

### Behandelte Bibliotheken

Dieses Dokument konzentriert sich auf:

* **RxJava**: Implementierung für Java
* **RxAndroid**: Erweiterung für Android-Anwendungen
* **RxSwing**: Erweiterung für Swing-Oberflächen

---

## 🧠 Behandelte Konzepte

* Asynchrone Programmierung
* Erweitertes Observer-Modell
* Datenströme (Observable)
* Funktionale Operatoren
* Asynchrone Fehlerbehandlung
* Vereinfachte Parallelität

Die Konzepte mögen auf den ersten Blick komplex erscheinen, werden jedoch schrittweise anhand detaillierter Beispiele eingeführt.
